# House-Price-Predictor

Simple House Price Predictor

This is a basic Machine Learning project that predicts the price of a house using details such as location, size, and number of rooms. The model is trained using past house data and uses regression to estimate house prices. It can help buyers, sellers, and property agents understand the possible value of a house.

How to Run

Open the project folder.
Open the terminal or command prompt.
Type: py house.py
Press Enter to run the program.
